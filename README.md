Изгиб Питона — игра «Змейка»

Учебный проект Яндекс Практикума. Игра реализована на Python с использованием библиотеки Pygame и принципов объектно-ориентированного программирования.

Установка и запуск

Требуется Python 3.10 или новее.

Создайте виртуальное окружение:

python -m venv venv

Активируйте его:

* Windows: venv\Scripts\activate
* macOS/Linux: source venv/bin/activate

Установите зависимости:

python -m pip install -r requirements.txt

Запустите игру:

python main.py

Управление

* Стрелки — изменение направления движения змейки.
* Esc — выход из игры.
* При столкновении с собственным телом змейка возвращается в начальное состояние.
* При поедании яблока змейка увеличивается на один сегмент.

Структура проекта

* the_snake.py — игровые классы, обработка клавиш и игровой цикл.
* main.py — запуск игры.
* requirements.txt — зависимости проекта.
* tests/ — тесты проекта.
